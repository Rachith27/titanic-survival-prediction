# 🚢 Titanic Survival Prediction

A machine learning project to predict survival of Titanic passengers using Random Forest Classifier.

## 📊 Project Overview
- **Competition:** Kaggle Titanic - Machine Learning from Disaster
- **Model:** Random Forest Classifier
- **Kaggle Public Score:** 0.74162

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Seaborn
- Matplotlib

## 📁 Project Structure
- **EDA** - Exploratory Data Analysis on passenger data
- **Data Cleaning** - Handling missing values in Age, Embarked, Fare
- **Feature Engineering** - Created FamilySize and IsAlone features
- **Model Training** - Random Forest Classifier with 100 estimators
- **Prediction** - Generated submission file for Kaggle
